## 2. 진입 패턴 정의

### 패턴 A — 폭등 후 첫 눌림목 (복기 비중 37%)

**발생 메커니즘:**
1. 대형 거래량 이벤트(≥3x 평균) + 당일 +5%+ 급등 발생
2. 이후 1~10 거래일 내 3~15% 눌림
3. 눌림목에서 거래량 재확인(≥1.2x) + 추가 급락 없음(-3% 이내)

**실사례 (복기):**
- 하나마이크론: 3/25 vol 13.2M(20배) 급등 → 3/31 눌림목(31,100) → 추천 → 4/1 즉시 반등
- 미코: 3/9 vol 4.8M(12배) +21% → 6주 공고화 → 2차 돌파 진입

**조건 상수:**
```
PA_VOL_MULT   = 3.0    // 이벤트일 거래량 최소 3배
PA_PRICE_MOVE = 0.05   // 이벤트일 최소 +5%
PA_DAYS_MIN   = 1      // 이벤트 후 최소 1일 경과
PA_DAYS_MAX   = 10     // 이벤트 후 최대 10일 이내
PA_PULLBACK_MAX = 0.15 // 최대 눌림 -15%
PA_PULLBACK_MIN = 0.03 // 최소 눌림 -3%
```

**목표/손절/보유:**
- 목표: 눌림폭 × 1.3 + 3% (최대 30%)
- 손절: ATR × 0.9 (최대 8%)
- 보유: 3거래일 기준

---

### 패턴 B — 조정 후 지지선 반등 (복기 비중 27%)

**발생 메커니즘:**
1. 최근 60일 고점 대비 -20~50% 조정 완료
2. 20~50일 전 박스권 평균가 ±8% 이내(이전 저항→지지 전환)
3. 당일 반등 시작(양봉) + 거래량 1.5x 이상

**실사례 (복기):**
- 이수페타시스: 11월 고점 161,400 → -32% 조정 → 3월 추천(109,600) = 5월 브레이크아웃 구간
- 알지노믹스: 12월 고점 234,500 → -38% → 이전 돌파 레벨(146,000) 재진입 → +38.36%
- 동진쎄미켐: 3개월간 51,800 지지선 유지 → 4월 추천 = 지지선 재확인 진입

**조건 상수:**
```
PB_CORR_MIN   = 0.20   // 최소 -20% 조정
PB_CORR_MAX   = 0.50   // 최대 -50% (그 이상은 붕괴 의심)
PB_LEVEL_PROX = 0.08   // 이전 박스권 레벨 ±8%
RSI14 범위     = 40~72  // 과매도 반등 직후 ~ 과매수 진입 전 구간만 인정
```

**목표/손절/보유:**
- 목표: 조정폭 × 45% (최소 10%, 최대 30%)
- 손절: ATR × 1.0 (최대 8%)
- 보유: 5거래일 기준

---

### 패턴 C — 촉매 이벤트 당일 (복기 비중 17%)

**발생 메커니즘:**
1. 임상결과/계약/특허 등 뉴스 발생 당일
2. 거래량 5배 이상 + 당일 +5%+ 급등
3. 종가가 일중 범위의 상단 50% 이상 마감 (추가 상승 여력 확인)

**실사례 (복기):**
- 로킷헬스케어: 2/5 임상 이벤트(vol 12.5M = 평균 대비 기록적) → 당일 +20.5%
- 삼성중공업: 3/17 수주 이벤트(vol 37M = 25배) → 1일 만에 +3%, 이후 38일 보유 +19.4%
- 대원전선: 이벤트 당일 추천, 익일 +16.86% 1일 청산

**조건 상수:**
```
PC_VOL_MULT  = 5.0   // 당일 거래량 5배+
PC_PRICE_MIN = 0.05  // 당일 +5%+
PC_STR_MIN   = 0.50  // 종가 강도(일중 상단 50%+)
RSI14 상한    = 82    // 82 초과 극단 과매수 구간 제외
```

**목표/손절/보유:**
- 목표: ATR × 1.8 (최소 10%, 최대 30%)
- 손절: ATR × 0.9 (최대 8%)
- 보유: 2거래일 기준 (빠른 청산)

---

### 패턴 D — 박스권 돌파 (복기 비중 13%)

**발생 메커니즘:**
1. 25거래일 이상 박스 공고화 완료
2. 박스 상단 돌파 당일 + 거래량 2.5배+ + +2%+
3. 일봉 정배열(SMA20 > SMA60) = 상승 추세 내 돌파

**실사례 (복기):**
- 파미셀: 장기 13,000~17,000 박스권 → 16,350 재진입 → 34일 보유 +11.31%
- 현대무벡스: 30,000~47,000 고점대 박스 → 33,400 재진입 → 59일 최장 보유 +18.56%

**조건 상수:**
```
PD_VOL_MULT  = 2.5   // 돌파 거래량 2.5배+
PD_BREAK_MIN = 0.02  // 돌파 당일 +2%+
PD_DAYS      = 25    // 박스권 기간(최근 25일 고점 기준)
```

**목표/손절/보유:**
- 목표: ATR × 1.5 (최소 10%, 최대 30%)
- 손절: ATR × 0.8 (최대 8%)
- 보유: 4거래일 기준

## 3. 스코어링 시스템

### 3.1 기본 점수 (패턴별)

| 패턴 | 기본 점수 | 복합 보너스 |
|------|:---:|:---:|
| C 촉매 이벤트 | 60점 | - |
| A 눌림목 | 50점 | A+B 동시: +15점 |
| B 지지선 반등 | 45점 | C+D 동시: +10점 |
| D 박스권 돌파 | 40점 | - |

### 3.2 보너스 지표 (10가지)

| 지표 | 조건 | 점수 |
|------|------|:---:|
| 거래량 등급 | 8x+ / 5x / 3x / 2x | +25 / +18 / +12 / +6 |
| OBV 수급 확인 | 수급 상승 추세 | +20 |
| 외국인+기관 동반 순매수 | 각 5억 이상 | +20 |
| 긍정 공시 | 계약/특허/수주 등 | +20 |
| 일봉 정배열 | SMA20 > SMA60 | +15 |
| MACD 골든크로스 | 0선 상향 돌파 | +15 |
| ADX 추세 강도 | ADX ≥20, +DI > -DI | +10 |
| RSI 골든존 | 50~70 구간 | +8 |
| 당일 장마감 강세 | 일중 강도 ≥70% | +12 |
| 52주 신고가 | 신고가 돌파 | +25 |

### 3.3 패널티 (2가지)

| 조건 | 점수 |
|------|:---:|
| OBV 수급 불일치 | -8점 |
| MACD 연속 음수 (패턴C 제외) | 강제 차단 (return) |

### 3.4 게이트 조건

```
최소 통과 점수: 60점 (패턴 기본점수 + 최소 1~2개 보너스 필요)
R:R 최소 비율: 1.5 이상
등급 기준:
  강매: 110점 이상
  급등: 패턴C + 거래량 8x+ + 당일 +8%+
  매도차익: 패턴C + 거래량 5x+ (강매/급등 미충족)
  매수: 나머지 통과 종목
```

## 4. 기초 필터 (5가지)

| 필터 | 조건 | 이유 |
|------|------|------|
| F1 최소 거래대금 | ≥ 50억원 | 유동성 보장 |
| F2 거래량 D-grade | ≥ 평균 × 1.0 | 노이즈 차단 |
| F3 RSI 침체 | ≥ 40 | 모멘텀 없는 하락 종목 제외 |
| F4 부정 공시 | 소송/횡령/배임/감사의견 없음 | 리스크 종목 제외 |
| F5 대량 순매도 | 외국인/기관 각 -10억 미만 | 기관 회피 종목 제외 |

---

## 5. 선정 필터

```
1. 등급 필터: 강매/급등/매도차익/매수 (관심 제외)
2. 동일 종목 중복 차단: 이번 주 이미 추천된 종목 코드 제외
3. 주간 한도: MAX_WEEKLY_SENDS (=15, 일 3건×5일 기준)
4. 정렬: 등급 우선(강매>급등>매도차익>매수) → 동일 등급 내 rankScore 내림차순
5. 최종 선정: 상위 MAX_STOCK_PER_SEND (=3)건
```

## 7. Acceptance Criteria

| # | 기준 | 검증 방법 |
|---|------|---------|
| AC-1 | 4개 패턴(A/B/C/D) 각각 독립적으로 감지 | 각 패턴 boolean 단위 테스트 |
| AC-2 | 기초 필터 5개 모두 적용 | 거래대금/RSI/DART/순매도 필터 통과 확인 |
| AC-3 | 스코어 ≥ 60 미달 시 candidates에 미등록 | 로그에서 pass/fail 확인 |
| AC-4 | R:R < 1.5 종목 제외 | 목표가/손절가 산출 후 비율 확인 |
| AC-5 | patternType 필드 candidates에 포함 | 텔레그램 알림 메시지 확인 |
| AC-6 | 동일 종목 주간 중복 차단 작동 | sentThisWeek Set 로직 확인 |
| AC-7 | 등급별 보유기간 차등 적용 | weeklyRecommendations holdingDays 확인 |
| AC-8 | 복합 패턴(A+B) 보너스 +15점 정상 누적 | 스코어 계산 로그 확인 |
